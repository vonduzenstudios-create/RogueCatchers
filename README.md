# RogueCatchers

A browser-based, 2D pixel-art monster catcher in the spirit of PokeRogue. Every sprite, tile, sound and song is generated by code at runtime: there are no image or audio files in this repo.

## Run it

```sh
npm install
npm run dev      # local dev server
npm test         # unit tests
npm run build    # production build in dist/
```

Controls: arrows or WASD to move, Enter/Space/Z to confirm, Esc/X to go back.

## Layout

- `src/engine/` game loop, scenes, input, seeded random numbers
- `src/gen/` procedural generators (font, tiles, characters, title art)
- `src/scenes/` title screen and game screens
- `tests/` Vitest unit tests

Pushes to `main` build and deploy to GitHub Pages through `.github/workflows/deploy.yml`.
